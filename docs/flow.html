🔄 検知 → 購入 → 監視 → 売却 → 検証、そしてまた検知へ

自動売買はしません。「機械が見張って知らせる」部分と「人が判断して動く」部分が 交互に並ぶループです。まず全体の形を見て、そのあと各段階の中身を確認してください。

自動(GitHub Actions) 手動(あなたの操作)
1

シグナル検知

自動・常時

4つのソースが独立に判定し、GitHub Actions経由でDiscordに通知します。

  • tech — SMA9/21クロス + RSI(30分毎)
  • dip — 売られすぎからの反転「⚡覚醒」(30分毎)
  • whale — Whale Alertの大口資金移動(15分毎)
  • macro — 雇用統計×金・ドル・株・VIX・原油・FF金利(月1回)
  • confluence — 上記が2つ以上一致したら強調通知
2

判断・購入・記録

手動

通知の方向・根拠・損切り目安を見て、買うかどうかは自分で決めます。

  • 取引所で購入(このシステムは発注しません)
  • journal_add.pyで建値・数量・損切りラインを記録
  • git pushしてリポジトリに反映
例:tech確認
🟢 BTC: LONG | 価格 $80,240 | RSI 45.8
→ 2回連続で同方向を確認済み。トレンド継続とみて購入
例:⚡覚醒(dip反転)
🔴 SOL: RSI 27 → 31(反転上昇)
→ 売られすぎからの反発初動とみて、押し目買いを検討
3

保有中の監視

自動・15分毎

記録したポジションを、条件を満たすまで繰り返し見張ります。

  • 利確目標(既定+5%)に到達したか
  • 損切りライン(記録時のstop_loss)を割ったか
  • その銘柄に新しいSHORTサインが出ていないか

いずれか該当 → Discordへアラート(該当なしなら次のチェックまで待機)

4

売却・記録

手動

アラート、または自分の判断で売り時を決めます。

  • 取引所で売却
  • journal_close.pyで決済価格を記録
  • git pushしてリポジトリに反映
例:利確
🟢 建値 $79,800 → 現在値 $83,900(+5.1%)
→ 利確目標+5%に到達。利益を確定して売却
例:損切り
🔴 損切りラインを割り込んでいます($2,430)
→ 記録した損切りラインに抵触。損失を確定して撤退
例:テクニカル悪化
⚠️ この銘柄でテクニカル的に売り(SHORT)サインも出ています
→ 含み益はあるが流れが変わった可能性。早めの利確を検討
5

検証・可視化

自動・継続

シグナルが実際に当たっていたか、記録した損益はどうだったかを機械的に検証します。

  • 的中率 — 1時間後/24時間後の方向が合っていたか
  • 目標到達率 — +5%に3日以内で届いたか、到達前の最大逆行幅
  • ペーパートレード — 全ソース分を実弾なしで自動シミュレーション
  • journal_report.pyで損益サマリー

この結果が「①のシグナルをどこまで信じてよいか」の判断材料として蓄積されていきます。

自動売買はしません。すべてのシグナルは参考情報であり、購入・売却は毎回あなた自身の判断です。
